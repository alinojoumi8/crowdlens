# Source review v4 verification protocol

Four new fictional cases: robotics demonstration, choir attendance, observatory sessions and orchard signage. Source texts, scope, comparison summaries and hashes are frozen before outputs. Development hearing regressions are separate; v2/v3 cases and judgments remain unchanged and are not rerun.

Run one actual MiniMax-M3 proposal attempt per case with unchanged request accounting: at most 12 aggregate requests/900 seconds, 180 seconds per proposal, no provider retries, JEV extra grading off, no automatic acceptance. Retain raw responses and all ready/blocked/failed/not-attempted outcomes. Record scope, document coverage and original-parent hashes. Billing amount is unknown without provider billing evidence.

New production policy requires complete explicit source-grounding audit records for all claims, including analysis premise chains; non-supported/ambiguous/unverified outcomes block. Summary consistency is mandatory even with edits. Automatic edits are confined to a unique verbatim selected-section occurrence in the frozen summary; all other text is protected. Unmapped abstract summaries stay unchanged for review. Existing proposals retain their earlier contracts; no guard is weakened to obtain ready output.

Export original documents and filenames, original/candidate summaries and raw/normalized edit requests. Any independent Astra review uses AI provenance and null human timing. No outcome-driven retries, prompt changes or rewriting of frozen evidence. This is a small proposal-path evaluation, not factual certification or upload-to-report E2E/release approval.
