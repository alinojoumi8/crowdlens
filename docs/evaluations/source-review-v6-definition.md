# Source review v6 protocol

Four fresh fictional domains: archive trolley, riverbank attendance, conditional pottery access and projector booking. Freeze sources, metadata, scope and summaries before actual provider outputs. One proposal attempt per case on a clean committed candidate, MiniMax-M3, JEV extra graders off, at most 24 aggregate requests and 900 seconds. Each phase may make one counted syntax correction only when the JSON parser fails; keep both completions and all budget/ledger admissions. No semantic or state retries, no automatic acceptance. All ready, blocked, failed and not-attempted cases remain in the denominator. No tuning or rerunning v6 after output inspection.

Server-generated summary sentences copy selected ledger claims. Audit judgment outcomes are separate from defects: complete per-claim, paragraph, edit and document coverage is mandatory. Non-supported judgments, omission uncertainty, missing coverage and inconsistent summaries block. Preserve v2-v5 and development failures; the development rota example is excluded. Independent Astra max review is AI with human timing null. This is proposal-path and summary verification, not release or general factual certification.
